# Douala Flow AI

Application web d'analyse des flux de transport urbain, cas de Douala (projet de Licence de Technologie, Génie Logiciel, IUT de l'Université de Douala).

- Carte plan, satellite et couche trafic Google (clé optionnelle)
- Itinéraires avec alternatives et niveau de congestion
- Enregistrement de trajets GPS depuis le téléphone
- Signalements, tableau de bord, prévisions, administration
- Base de données Supabase (PostgreSQL, Auth, RLS)

Application en ligne : https://ouinou.github.io/douala-flow-ai/
